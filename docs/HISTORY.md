# История матчей: почему её не было и откуда она взялась

## Коротко

- Game Coordinator отдаёт только **последние 8 матчей**.
- Демки Valve живут **около 30 дней**, поэтому задним числом их не скачать.
- Leetify собирает историю **непрерывно с момента подключения** и хранит разобранные матчи.
- Мы импортировали **540 матчей Leetify** (с 2021-11-29) и **7 свежих матчей** через GC + демки.

## Источники в БД

| `matches.source` | Что внутри | Глубина |
|---|---|---|
| `gc` | score, map, K/D/A, HS, раунды, demo URL | последние 8 |
| `gc` + демка | + ADR, KAST, HLTV 2.0, киллфид, damage, shots, grenades, positions | ~30 дней |
| `leetify` | score, map, K/D/A, ADR, HS%, HLTV, Leetify Rating, Aim/Utility/Positioning | вся история Leetify |

## Почему у Leetify «всё», а у нас нет

Leetify обрабатывает матч сразу после игры: скачивает демку, считает метрики и хранит результат. Мы подключились позже, поэтому старые демки уже удалены Valve. Восстановить по ним aim/utility/positions невозможно — этих данных больше нигде нет.

Для старых матчей доступны только агрегаты, которые Leetify сохранил. Они импортированы и помечены `source='leetify'`.

## Как импортировать историю Leetify

Импорт выполняется из браузера, где открыт Leetify (используется ваш `access_token` из localStorage):

1. Открыть Leetify в браузере OpenCode.
2. Выполнить скрипт из `docs/leetify-import.js` (постранично тянет `/api/v2/games/history` и POST-ит на `http://127.0.0.1:8787/api/import/leetify`).
3. Сервер дедуплицирует матчи по времени и карте и пишет `source='leetify'`.

Скрипт не публикует токен и не отправляет его на сервер — только сами матчи.

## Что теперь реально считается

- win rate, K/D, ADR, HS%, KAST (где есть демка), HLTV 2.0, Leetify Rating;
- Aim / Utility / Positioning ratings (из Leetify);
- карты, счёт, результаты;
- для 7 свежих матчей: киллфид, damage, shots, accuracy, grenade counts, positions.

## Что всё ещё требует демки

- TTD/TTK/preaim/спрей — нужна видимость и покадровые углы;
- 2D-реплей, зоны, heatmaps;
- клатчи, опенинги, trade-события;
- экономика по тикам.

Это считается только для матчей, у которых демка была скачана вовремя. Для старых матчей таких данных нет и уже не будет.

## Полная история через Steam

Если не хотите зависеть от Leetify:

1. `STEAM_API_KEY` в `.env`.
2. Game Authentication Code + самый старый share-код из Steam Support / gcpd.
3. В приложении: Steam → «Полная история» → заполнить и запустить.

Steam отдаст цепочку share-кодов, GC — summary матчей. Детали (демки) будут только для тех, что ещё живы.
