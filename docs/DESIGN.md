# Midnight Royale — дизайн-система v2.0

Визуальный язык приложения: глубина, точность, сдержанное барочное наследие.
Токены живут в `apps/web/src/styles.css` в блоке `:root`.

## Правила

- 75–80% площади — тёмные поверхности, до 2% — золото.
- Золото — подпись бренда, не универсальный цвет «хорошо». Для «хорошо» используется
  `--success`, для «плохо» — `--danger`.
- Карточки различаются глубиной поверхности (`navy-850` → `navy-800` → `navy-700`),
  а не цветом.
- Границы 1px, прозрачность 50–70%. Тени глубокие и мягкие.
- Орнамент — тональная роза в фоне (`body::before`), прозрачность 5%, никогда не
  под плотными таблицами и графиками.
- Один выразительный акцент на визуальную область.

## Типографика

Montserrat (Google Fonts), `tabular-nums` для всех чисел.

| Элемент | Размер | Вес |
|---|---|---|
| Page title | 32–52px | 600 |
| Section title | 20px | 600 |
| Card title | 13–16px | 600 |
| Body | 14px | 400 |
| Secondary | 12–13px | 400 |
| Caption | 10–11px | 400/500 |
| Overline | 10–11px | 500, uppercase |

## Геометрия

`--radius-lg: 12px` панели · `--radius: 10px` карточки · `--radius-sm: 8px`
вложенные карточки, кнопки, input · `--radius-badge: 6px` бейджи.

Spacing: 8-px система — 4 / 8 / 16 / 24 / 32 / 48.

## Компоненты

| Компонент | Реализация |
|---|---|
| Sidebar / Header | `navy-900` / прозрачный navy + тонкая граница и золотая линия |
| Main card | `navy-850` + лёгкий верхний градиент |
| Nested card | `navy-800` |
| Primary button | золотой фон, тёмный текст |
| Secondary button | `navy-700` + граница |
| Accent action | розовый (`--pink`) |
| Badge | тёмная поверхность + цветной индикатор |
| Tooltip | `navy-700` + граница, непрозрачный фон |
| Input / Select | `navy-800`, focus-ring золотой |
| Активный фильтр | золотая граница + золотой label, плюс chip |

Все интерактивные элементы имеют состояния: default, hover, focus, active,
disabled; loading — через opacity/skeleton.

## Графики

- Розовый — главная серия / игрок.
- Фиолетовый — альтернативная серия.
- Синий — дополнительная серия.
- Золотой — агрегаты и брендовые акценты (не для «хорошо»).
- Зелёный — успешные значения.
- Сетка `rgba(32,52,91,.55)`, без тяжёлых осей, tooltip на `navy-700`.

## Доступность

- Focus-visible — золотой outline 2px.
- `prefers-reduced-motion` отключает анимации.
- Минимальный контраст текста: основной `#F2F5FC`, вторичный `#8492AD` на navy-поверхностях.
